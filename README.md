# chepeti-web
Сайт chepeti.com (GitHub Pages, публікується push у main): політика конфіденційності, умови, сторінка видалення акаунта
(українською і англійською в `en/`), сторінки запрошення й скасування зміни пошти, `maintenance.json` (технічні роботи,
застосунок читає при запуску), `app-ads.txt`.

Перелік пропозицій партнерів тут не лежить: застосунок читає його з окремого репозиторію `chepeti-partners`, редагує адмінка.
Українські й англійські сторінки політики, умов і видалення змінюються разом; при новій редакції — `LEGAL_DOCS` у застосунку.
